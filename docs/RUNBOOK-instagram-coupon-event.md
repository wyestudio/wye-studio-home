# 인스타 댓글 이벤트 쿠폰 — 운영 안내서

작성 2026-09-16 · 캠페인 「인스타 댓글 이벤트」 (키 `instagram_grand_open_202609`)

> **운영 방식: 수동 발급.** ManyChat 자동화는 도입하지 않기로 했다(2026-09-16).
> 이유 — 참여자 규모에 비해 ManyChat Pro 구독·14일 체험 만료 관리 비용이 크다.
> 자동화용 API 는 만들어 두었고 동작도 확인했다. 나중에 참여자가 늘면 6번대로 켜면 된다.

---

## 1. 매일 하는 일

1. 이벤트 게시물의 **새 댓글**을 본다
2. 그 계정이 **팔로우했는지 / 좋아요 눌렀는지** 눈으로 확인한다
   (인스타 앱에서 본인 게시물의 좋아요 목록을 볼 수 있다)
3. 조건을 채웠으면 **어드민에서 코드를 뽑아 DM 으로 보낸다** → 2번 항목

## 2. 코드 뽑는 법

**어드민 → 쿠폰 → 인스타 댓글 이벤트 → `코드` → 「인스타 아이디로 발급」**

아이디를 넣고 「쿠폰 발급」을 누르면 코드가 나온다. `@` 를 붙이든 대문자를 쓰든 상관없다.

⚠️ **같은 계정을 두 번 넣어도 새 코드가 안 나간다.** 「이미 받아간 계정 — 같은 코드」
라고 알려주고 그때 준 코드를 그대로 보여준다. 누구에게 줬는지 따로 적어둘 필요가 없다.

누가 어느 코드를 받아갔는지는 아래 표의 **「받아간 계정」** 칸에서 볼 수 있고,
CSV 내려받기에도 함께 나온다.

## 3. DM 문구 (복사해서 쓰기)

```
🚀 우주이스케이프 GRAND OPEN EVENT 참여 완료!

예약 시 아래 쿠폰 코드를 입력하시면 총 결제금액에서 5,000원이 할인됩니다.

🎟️ 쿠폰 코드
{코드}

🔗 예약하기
https://www.wouldyouescape.com/open-event

· 10월 4일 회차 잔여석 마감 시까지 사용 가능
· 계정당 1회 사용 가능
· 잼핏 전용 1,000원 쿠폰과 중복 사용 가능
· 프리오픈 쿠폰과 중복 사용 불가

※ 쿠폰 수령만으로 좌석이 확보되지는 않으며, 각 회차는 결제 완료 순으로 마감됩니다.

그럼, 바-ㅇ탈출에서 만나요!🪐
```

⚠️ 예약 링크는 **`/open-event`** 를 쓴다. 테마 주소를 직접 쓰면 유입경로(utm)가 안 붙어
"인스타 이벤트로 몇 명이 왔는지" 를 분석에서 볼 수 없다.

## 4. 이벤트를 끝낼 때

잔여석이 마감되면 **어드민 → 쿠폰 → 인스타 댓글 이벤트 → 수정 → 「사용 가능」 끄기**.
이미 나간 코드는 유효기간(10/4)까지 그대로 쓸 수 있다.

## 5. 쿠폰 규칙 (고객 안내용)

| | |
|---|---|
| 할인 | 예약 1건당 5,000원 |
| 기간 | 2026-09-16 ~ 10-04 |
| 대상 | 바-ㅇ탈출 |
| 중복 | 잼핏 쿠폰과 ✅ · 프리오픈 쿠폰과 ❌ |
| 발급 수량 | 300장 |

## 6. (나중에) 자동화를 켜고 싶어지면

만들어 둔 것: `POST /api/coupons/instagram/claim` (Bearer 인증),
`assign_coupon_to_handle()` DB 함수, `MANYCHAT_WEBHOOK_SECRET` 환경변수.
**테스트 완료** — 신규/재요청 멱등, 대소문자·`@` 정규화, 소진·종료 분기, 인증 실패까지 확인.

필요한 것: ManyChat **Pro**(External Request 가 Pro 전용). 흐름은
댓글 트리거 → DM → 「Follows your account」 조건 → External Request → 코드 DM.

⚠️ **좋아요 여부는 어떤 도구로도 자동 확인할 수 없다.** 인스타(메타)가 좋아요 누른
사람 목록을 외부에 공개하지 않는다. 자동화하더라도 좋아요는 눈으로 봐야 한다.

⚠️ 자동화를 켤 때는 **"코드가 비었을 때" 분기를 반드시 만든다.** 구독이 끊기거나
서버가 응답하지 않으면 코드만 비어서 *"쿠폰 코드: (빈칸)"* 인 DM 이 나간다.

## 7. 롤백

- **발급 중단**: 캠페인 「사용 가능」 끄기 (나간 코드는 유효)
- **API 만 막기**: Vercel 에서 `MANYCHAT_WEBHOOK_SECRET` 삭제 → 전부 500
- **기능 되돌리기**:
  ```sql
  drop function if exists public.assign_coupon_to_handle(text, text);
  drop index if exists public.coupons_campaign_handle_uidx;
  alter table public.coupons drop column if exists issued_to_handle;
  ```
  ⚠️ `issued_to_handle` 을 지우면 **누가 어느 코드를 받아갔는지 기록이 사라진다.**
  지우기 전에 CSV 로 내려받을 것.
