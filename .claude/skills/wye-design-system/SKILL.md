**"조금 줄여 달라" 는 한 단계 내려 달라는 뜻이다.** 13px 을 12px 로 깎지 말고
`text-label` 을 `text-micro` 로 바꾼다. 중간값을 새로 만들지 않는다.
← 척도를 벗어난 값 하나가 다음 사람의 근거가 된다 (경위: `docs/06-decisions.md` D-11)

## 이 중 하나라도 하면 이 문서를 먼저 읽는다

- 사용자가 **"작게 · 크게 · 넓혀 · 붙여 · 연하게 · 진하게"** 라고 말한다
- `className` 에 `text-` · `p-` · `m-` · `gap-` · `rounded-` · `max-w-` 를 새로 적거나 고친다
- `text-[13px]` · `p-[7px]` · `style={{ fontSize }}` 처럼 **수치를 직접 박는다**
- `src/app/globals.css` 의 `@theme` 블록을 건드린다

---

## 글자 — 크기가 아니라 **역할**로 고른다

| 토큰 | 쓰는 자리 |
|---|---|
| `text-display` | 메인 히어로, 단체 예약 H1 |
| `text-h1` | 페이지 제목 |
| `text-h2` | 섹션 제목 — H1 보다 반드시 작게 |
| `text-h3` | 카드 제목 · 시놉시스 |
| `text-body` | **설명문 전부** |
| `text-body-sm` | 각주 · 보조 안내 |
| `text-label` | 입력 라벨 · 탭 · 날짜 |
| `text-micro` | 배지 · 영문 섹션 라벨 — **이보다 작게 쓰지 않는다** |
| `text-input` | 입력칸 전용 — 16px 미만이면 아이폰이 포커스 때 화면을 확대한다 |

- **`sm:` · `lg:` 로 크기 사슬을 만들지 않는다** ← 토큰이 `clamp()` 라 한 클래스가
  모바일↔데스크톱을 다 맡는다. 사슬을 쓰면 모바일이 기준 아래로 내려간다
- **커 보인다고 역할을 바꾸지 않는다. 글자가 아니라 칸을 줄인다**
  ← 설명문을 `body-sm` 으로, 라벨을 `micro` 로 내리면 역할표를 벗어난다
- 글자가 아닌 것(이모지·아이콘)에는 쓰지 않는다 ← 역할 이름이 안 맞는다

## 굵기 — 셋

`font-normal`(본문) · `font-semibold`(강조·라벨·카드 제목) · `font-extrabold`(페이지·섹션 제목).
**`font-bold`(700) · `font-medium`(500) · `font-black`(900) 을 새로 쓰지 않는다**
← 700 이 "강조" 와 "제목" 의 경계를 흐린다

## 면과 선 — 밝기가 아니라 **역할**

`bg-fill-subtle` / `bg-fill` / `bg-fill-strong`, `border-line-subtle` / `border-line` / `border-line-strong`.

- **`bg-white/[0.04]` · `border-white/30` 처럼 투명도를 직접 적지 않는다**
- **`fill-strong`·`line-strong` 은 "더 진한 색" 이 아니라 hover·선택 상태다**
  ← 밝기순으로 바꿔치우면 눌렀을 때 반응이 사라진다 (달력 · 회차 선택 · 진행바)

## 둥글기 — 셋

`rounded-md`(배지·칩) · `rounded-lg`(버튼·입력칸·카드) · `rounded-xl`(큰 패널).
`rounded-full` 은 크기가 아니라 모양이라 따로다(알약·원).
**`rounded`(4px) · `rounded-2xl`(16px) 을 새로 쓰지 않는다.**
`rounded-none` 은 도트 게임 느낌을 내는 자리에서만 의도적으로 쓴다(테마 상세의 모드 창).

## 가운데 틀 폭

`max-w-5xl`(사이트 틀) · `max-w-4xl`(달력) · `max-w-3xl`(읽는 글·상세 블록) ·
`max-w-2xl`(신청 폼) · `max-w-md`(입력 두세 칸).
**한 페이지 안에서 블록마다 다른 폭을 쓰지 않는다** ← 스크롤하면 본문 좌우 끝이
계단처럼 움직인다

## 여백 — Tailwind 눈금에서 한 칸씩

간격은 별도 토큰이 없다. **Tailwind 기본 눈금(4px)** 이 척도다 — 넓히려면
`pt-5 → pt-6 → pt-8` 로 칸을 옮긴다. `p-[7px]` · `gap-[13px]` 로 박지 않는다.

예외는 **광학 보정**뿐이다(큰 숫자 옆 글자의 `-ml-1.5` 처럼). 그런 값에는
**왜 그 수치인지 주석을 붙인다.**

## 척도 밖 예외

**가격표의 금액 숫자**(`PriceTable`) 하나뿐이다. 새 예외를 만들려면 왜 토큰으로
안 되는지 주석에 적는다.

## 고치고 나면 확인한다

브라우저로 **390px 과 1280px 둘 다** 본다. 글자가 칸 밖으로 넘치는지
(`scrollWidth > clientWidth`)와 가로 스크롤이 생겼는지를 같이 잰다
← 줄인 쪽은 눈으로 안 보이고, 늘린 쪽은 잘린다
